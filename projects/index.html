Gigawatt Ledger

Tracks AI spending from big tech’s filings to the power grid

A daily pipeline joins SEC filings from 26 companies across the AI supply chain (cloud buyers, chips, servers, power equipment, data-center landlords and utilities) with hourly electricity demand in five data-center regions, weather removed. Every number keeps the date it became public, so any past day can be replayed without hindsight.

An AI analyst answers questions from the data and 4,600+ filing passages through 16 tools. Code checks every number it writes before you see it, and an eval suite of 22 cases, prompt injection included, runs it end to end.

In 2026Q2, how many dollars did the four hyperscalers spend on capex for every dollar of NVIDIA revenue?

In 2026Q2, the four hyperscalers (Microsoft, Alphabet, Amazon and Meta) spent about $1.72 of capex for every $1 of NVIDIA revenue.

  • Hyperscaler capex in 2026Q2 was $165.05B.
  • NVIDIA revenue in 2026Q2 was $96.22B.
  • $165.05B ÷ $96.22B = 1.7153, which rounds to 1.72.

Recent quarters for comparison:

  • 2025Q4: $118.63B ÷ $68.13B = 1.7412.
  • 2026Q1: $129.75B ÷ $81.61B = 1.5899.
  • 2026Q2: 1.7153.

A real answer from an eval run. Every figure in it was checked against the data before it was shown.

def matches(value: float, unit: str, decimals: int, evidence: list[float]) -> bool:
    for v, f in _candidates(value, unit):
        # half a unit in the last shown digit (scaled into evidence units: "4.9 GW" = ±50 MW), or 0.5%
        tol = max(0.5 * 10 ** (-decimals) * f, abs(v) * 0.005)
        if any(abs(v - e) <= tol + 1e-9 for e in evidence):
            return True
    return False

def verify(text: str, evidence: list[float]) -> Report:
    rep = Report()
    for raw, value, unit, decimals in extract(text):
        rep.checked.append(raw)
        if not matches(value, unit, decimals, evidence):
            rep.unverified.append(raw)
    return rep

Sundown

How batteries carry U.S. grids through the evening peak

Every morning a pipeline pulls hourly data for the seven major U.S. grids into SQL with Airflow and Spark, checks it, and rebuilds a live dashboard. Batteries now cover about a quarter of California’s evening peak.

The quality checks and 59 tests caught 3 errors in the government’s own source data. The carbon analysis shows midday EV charging in California emits about 60% less CO₂ than overnight.

California, an average day
daily_net_peak AS (
    SELECT *,
           ROW_NUMBER() OVER (PARTITION BY region_code, day ORDER BY net_load_mwh DESC) AS rn,
           COUNT(*)     OVER (PARTITION BY region_code, day)                            AS hours
    FROM hourly
)
SELECT region_code,
       day,
       period_utc                                       AS net_peak_hour_utc,
       ROUND(demand_mwh)                                AS demand_mwh,
       ROUND(net_load_mwh)                              AS net_load_mwh,
       ROUND(battery_mwh)                               AS battery_mwh,
       ROUND(100.0 * battery_mwh / NULLIF(net_load_mwh, 0), 1) AS battery_share_of_net_peak_pct
FROM daily_net_peak
WHERE rn = 1 AND hours >= 22                             -- complete days only
ORDER BY region_code, day;
